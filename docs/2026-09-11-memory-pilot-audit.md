## 可成立的判断

1. “这三份记录记忆百分比相对较低”成立；“所有学生记忆能力普遍偏低”不成立，样本量与测量等难度证据不足。
2. 失分集中度最突出的是 M03。它同时要求记两组顺序，并穿插其他题组；是下一轮优先检查对象。但 6 次小题作答太少，不能据此判定学生都在猜。
3. M04/M05 实际间隔长且个体间差异明显。按穿插题组数量安排延迟，并不等于每位参与者经历了相同时间；阅读/解题速度、停留均可能影响结果。现有数据不能确定因果。
4. M01 与 M05 既用不同目标子集又问不同内容（图形识别/位置）；M02 与 M04 目标配对不同；M03 与 M06 询问方式不同。不得直接用这些正确率相减计算遗忘率，或据六项高于四五项就宣布难度颠倒。
5. 现有元数据没有“不记得”选择和充分的展示/前后台记录，不能证明或反驳“基本靠猜”，也不能识别图形过小或未看清造成的个体失分。

## 后续处理边界

- 已获用户同意的体验方向：减少阅读负担、统一放大图形、序列放慢并增加准备/组间提示、正式材料以外的示范练习、不记得选项、后台作答过程计时。
- 不直接提高记忆分数，不降低支持阈值，不重算已有报告。
- 对 M03 优先做同规则练习和展示体验调整；M04/M05 的延迟安排需另行明确方案，不在本次只读核验中直接重排题目。
