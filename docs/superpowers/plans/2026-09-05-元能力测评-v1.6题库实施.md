# 元能力测评 V1.6 题库实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 在保留现有移动端结构和视觉的前提下，用可审计的 V1.6 数据源替换真实题库、评分、记忆流程和报告解释，并输出可运行独立 HTML。

**Architecture:** 新建单一 V1.6 题库，内部标注和学生端任务由同一数据生成；评分层把任务内部正确率折算为一分；记忆材料通过显式呈现阶段与不重叠目标子集隔离。审计脚本从题库生成完整题目清单、覆盖表、时长和预测试风险。

**Tech Stack:** React 18、TypeScript、Vite、Vitest、Testing Library、Node.js。

**Spec:** docs/superpowers/specs/2026-09-05-元能力测评-v1.6题库改版-design.md

## Global Constraints

- 正式任务恰好三十个；五项元能力各六个；十五项二级能力各两个。
- 每项元能力均为两个基础、三个中等、一个挑战。
- 每个任务单元统一一分；多小题先算内部正确率；反应时间只记录。
- M01/M05 与 M02/M04 分别使用不重叠即时、延迟目标子集。
- R04 使用双重符号或属性变化规则，不使用复杂空间旋转。
- 现有报告保持完整展开；学生端把“准确表达”显示为“表达辨析”。
- 项目目录不是 Git 仓库，实施中用测试通过作为检查点，无法创建提交。
