# 《元能力快速测评 V1.0》15 个二级机制任务规格表

状态：专家设计规格，供候选任务生产、审核、认知访谈与试测使用  
版本：Task Specification 1.0-draft  
依据：`2026-09-01-元能力快速测评-v1-design.md`  
适用对象：浙江新高考高一、高二、高三及复读学生  
定位说明：本文没有使用真实学生访谈、认知访谈或试测数据，不代表任务已经验证，也不冻结题目参数、计分界限或正式报告规则。

## 0. 使用规则

### 0.1 本文件是什么

本文把蓝图中的 15 个二级机制展开为 30 个任务节点规格。每个机制正好包含任务 A、任务 B 两个不同情境。规格描述出题人员要测什么、学生需要怎样思考、材料和交互应满足什么条件，以及答题结果可以支持怎样的克制解释；不提供最终题干、最终素材、最终选项或固定分数阈值。

### 0.2 全局出题合同

1. 每个节点可以包含 1—3 个共享同一材料和操作过程的微判断。微判断只是节点内部评分点，不得拆成独立题，也不得把微判断数量当作独立证据数量。
2. 每个机制的判断必须综合任务 A 与任务 B。任何单一节点、单一微判断、单一呈现形式都不能独立决定机制优势。
3. 不预设“答对几个即为优势”的固定阈值。节点参数、评分点权重、证据状态界限均须在认知访谈、封闭试测和校准后版本化确定。
4. 速度不直接加分或扣分。有效作答时间只用于识别乱答、中断、材料过长、设备负担以及跨表征任务的匹配情况。
5. 所有材料使用初中生也能看懂的日常语言，不要求高中公式、学科术语、文学常识、数列套路或特定课程知识。
6. 排序、配对、拖动和空间操作都必须提供点击式替代；不依赖颜色、微小细节、精准拖动或屏幕尺寸制造难度。
7. “目标难度”是专家制作目标，不是已验证难度。容易、中等、小挑战都须由目标心理操作本身造成。
8. “可进入报告的解释”只能在任务有效、质量标记正常，并与同机制另一任务形成相符证据时使用；实际文案还要受计分规则版本和受控文案库约束。

### 0.3 记忆材料总合同

- Deck A、Deck B 各含 6 组陌生“图符—双音节虚构名称”配对。虚构名称只使用易辨认的常用音节组合，但组合本身不是真实词；图符不使用交通标志、应用图标、字母、生肖等熟悉符号。
- 两套 Deck 在图符笔画量、视觉复杂度、虚构名称长度、音节相似度和配对关系上保持平行，但整体轮廓风格不同，学生能清楚知道已经换了一套材料；不能只换颜色。
- 每套 Deck 固定分为三个互斥子集：1—2 只用于快速记住，3—4 只用于保持记忆，5—6 只用于准确想起。一个材料项目只进入一个计分节点。
- Deck A 统一呈现约 40 秒；Deck B 在节点 18 开始时呈现，初始制作按 35 秒，后续只允许在 30—40 秒范围内根据试测校准。
- 呈现阶段不要求作答，不允许暂停、回看或主动复习。错误选项只从同一 Deck 的已呈现材料或匹配的陌生干扰材料中产生，不能让“从未见过”成为明显线索。

### 0.4 四组跨表征同构对照

| 对照组 | 节点 | 两种表征 | 底层关系控制 | 使用边界 |
|---|---|---|---|---|
| CR-1 | 03 / 16 | 文字意义 / 数量关系 | 三个对象间的部分—整体与限制关系；相同信息数、推理步数、选项数和猜对概率 | 节点表现可与同机制另一任务共同提供证据；03 与 16 的形式差异只作辅助研究证据，不单独进入优势判断 |
| CR-2 | 05 / 19 | 图形结构 / 文字关系 | 三层部件的连接、从属与共享关系；相同节点数和关系数 | 同上；不得据此给出固定“图形型”或“文字型”标签 |
| CR-3 | 09 / 22 | 数量变化 / 抽象规律 | 两种变化交替出现并共同决定下一状态；相同步数和候选数 | 同上；不得把数值计算或熟悉数列经验混入规律任务 |
| CR-4 | 11 / 26 | 空间转换 / 条件推导 | 连续两步操作及顺序不可交换；相同中间状态数和判断数 | 同上；不得把空间操作差异直接解释为推理能力高低 |

以下所有标记“跨表征”的节点均执行同一限制：它不能单独决定机制状态或一级能力结果；成对差异不进入主要能力分数；只有经人工同构复核、样本难度匹配和设备/阅读负担排查后，才可能以克制方式进入正式报告。

## 1. 记忆

### 1.1 快速记住

学生能听懂的定义：第一次接触新信息时，能较快留下清楚印象。

#### 任务 A：节点 01｜Deck A 新图符贴签

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量 Deck A 首次短暂呈现后，对子集 1—2 两组“图符—虚构名称”新对应关系的即时编码与提取，不测熟悉知识。 |
| 学生心理操作 | 在统一呈现阶段把陌生图符与虚构名称绑定；材料消失后，根据完整图符立即找出刚刚与它配对的虚构名称。 |
| 材料形式 | Deck A 全部 6 组同时呈现；计分只取子集 1—2。提取页一次呈现一个完整图符和同 Deck 的虚构名称选项，选项字形长度一致。规格不固定具体图符、虚构名称和选项顺序。 |
| 交互形式 | 单项选择后确认；含 2 个共享“刚看完 Deck A”情境的微判断，不显示即时对错。 |
| 可观察证据 | 子集 1—2 的对应选择；是否把两个同 Deck 虚构名称互换；首次操作、修改和有效作答时间作为质量信息。 |
| 评分点 | 每组图符与唯一虚构名称对应正确各为一个候选评分点；正式权重和有效证据界限待校准，不按速度加减分。 |
| 主要干扰 | 图符或名称本身熟悉；某个虚构名称更显眼；位置记忆代替配对记忆；反复观看；错误项来自未见材料。 |
| 排除设计 | 使用预审为陌生的图符和非词虚构名称；呈现时随机化位置且提取时重新排布；各名称等长、视觉突出度接近；所有干扰来自同 Deck；材料只呈现一次。 |
| 预计时间 | Deck A 呈现约 40 秒另计；本节点作答 15—20 秒。 |
| 目标难度 | 容易。目的是观察能否迅速留下新配对，不以大量相似干扰把学生难住。 |
| 与另一任务的差异 | A 使用轮廓偏封闭的 Deck A，在整套材料呈现后立刻完成“图符找虚构名称”；B 使用风格不同的 Deck B，并改为“虚构名称找图符”，避免完全复刻同一提取方向。 |
| 可进入报告的解释 | 若与任务 B 方向一致，可写：“在这次任务中，你第一次看到新的符号和名称时，能较快把对应关系留下来。”不得写成“记得快”这一固定天赋。 |

#### 任务 B：节点 18｜Deck B 新符号登记

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 用平行但不同的 Deck B，再次观察首次接触后快速形成新配对印象的表现，排除只适应 Deck A 风格的可能。 |
| 学生心理操作 | 在 Deck B 限时呈现中建立 6 组配对；材料消失后，根据完整虚构名称立即找回对应图符。 |
| 材料形式 | Deck B 6 组材料，计分只取子集 1—2；提取页给出一个虚构名称和多个同 Deck 图符，图符大小、线宽和复杂度匹配。 |
| 交互形式 | 图形单选后确认；2 个微判断共享同一次 Deck B 呈现。图形可放大，选择不依赖精准点按。 |
| 可观察证据 | 能否在反向提示下选回准确图符；相似轮廓间的混淆类型；修改次数和异常过快作答作为质量标记。 |
| 评分点 | 每个目标虚构名称对应正确图符各为一个候选评分点；不设置固定正确数阈值，最终计分与任务 A 的难度需经同年级样本校准。 |
| 主要干扰 | 学生沿用 Deck A 材料；只记位置；图符可按常识命名；小屏看不清；提取方向变化造成额外理解负担。 |
| 排除设计 | Deck B 与 A 在整体风格上清楚区分且无重复图符/虚构名称；提取前用不计分示意说明“看到名称选符号”；选项重新排布、可放大；所有干扰来自 Deck B。 |
| 预计时间 | Deck B 呈现初始按 35 秒另计；本节点作答 15—20 秒。 |
| 目标难度 | 容易。与任务 A 的预期难度接近，反向提示的额外负担须在试测中检查。 |
| 与另一任务的差异 | B 使用 Deck B 和“虚构名称找图符”的反向提取；A 使用 Deck A 和“图符找虚构名称”。两者材料、位置与视觉风格均不重复。 |
| 可进入报告的解释 | 若两节点证据相符，可写：“在这次任务中，你在两套不同的新材料里，都比较快建立了符号和名称的联系。”不能把 A/B 表现差异解释为长期稳定性。 |

### 1.2 保持记忆

学生能听懂的定义：经过一段时间和其他任务干扰后，信息仍能保留下来。

#### 任务 A：节点 07｜Deck A 延迟查签

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量 Deck A 子集 3—4 在完成节点 01—06 的其他任务后是否仍被保留；这是这两个项目的第一次提取。 |
| 学生心理操作 | 在没有复习的情况下，从较早呈现的 Deck A 中保留配对痕迹；看到图符后识别原配虚构名称。 |
| 材料形式 | Deck A 子集 3—4 的完整图符作为提示；选项来自 Deck A 的其他虚构名称，长度与视觉形式一致。节点 01 从未出现子集 3—4。 |
| 交互形式 | 每个提示一次单选并统一确认；2 个微判断共享“较早看过的那套材料”说明。 |
| 可观察证据 | 延迟后对子集 3—4 的准确对应；是否被 Deck A 内其他配对吸引；中断、后台时长和是否恢复会话作为证据质量标记。 |
| 评分点 | 两组延迟对应各为一个候选评分点；保持时距作为任务版本参数记录，不因作答快慢加分。固定状态界限留待校准。 |
| 主要干扰 | 节点 01 重复测试产生练习效应；中途回看；选项给出明显排除线索；不同学生实际延迟时距差异过大。 |
| 排除设计 | 节点 01 只测子集 1—2；节点 02—06 不出现任何 Deck A 元素；提交后不可返回；提示与选项同质；记录从 Deck A 消失到节点 07 素材显示的实际有效间隔。 |
| 预计时间 | 15—20 秒；预期有效延迟约由节点 01—06 形成，具体时距随全流程试测记录而非写死。 |
| 目标难度 | 中等。难度来自延迟与插入任务，不来自相似到难以辨认的材料。 |
| 与另一任务的差异 | A 的延迟发生在测评前半段，插入任务较少，采用“图符找虚构名称”；B 的延迟发生在后半段，插入任务类型不同，并采用配对表补空形式。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“在这次任务中，隔了一段时间、做过其他任务后，你仍能保留之前没有被提醒过的信息。”不得说成跨天或长期记忆能力。 |

#### 任务 B：节点 24｜Deck B 延迟补档

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量 Deck B 子集 3—4 在节点 19—23 干扰后首次被提取时的保留情况，提供与 Deck A 不同场景的同机制证据。 |
| 学生心理操作 | 保持新配对；在看到两张不完整登记卡时，从同 Deck 图符池中补回与虚构名称相配的图符。 |
| 材料形式 | 两张只显示目标虚构名称的卡片和一个含同 Deck 图符的候选池；计分项目仅为 Deck B 子集 3—4，之前节点没有出现它们。 |
| 交互形式 | 点击虚构名称卡，再点击图符完成配对；可随时修改，最后统一确认；提供清晰选中状态和键盘替代。 |
| 可观察证据 | 两张卡是否恢复正确；是否发生互换；完成路径和修改只作过程信息；后台或断点恢复导致的异常间隔进入质量标记。 |
| 评分点 | 每张卡的唯一正确配对各为一个候选评分点；互换按两个配对点分别记录，但属于同一节点，不当作两个独立题。 |
| 主要干扰 | 配对操作负担；卡片位置提示；节点 18 意外测到子集 3—4；候选池含未见图符导致排除容易。 |
| 排除设计 | 节点 18 严格只取子集 1—2；点击配对前给不计分操作示例；候选均来自 Deck B；每个会话随机卡片和候选位置；移动端目标区不小于 44×44px。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 中等。需在试测中与任务 A 的实际保留间隔和操作负担共同校准。 |
| 与另一任务的差异 | B 使用 Deck B、后半程不同干扰任务和“卡片—图符池”配对；A 使用 Deck A、前半程延迟和逐项单选。 |
| 可进入报告的解释 | 若两次延迟证据相符，可写：“这次任务里，即使中间换了几类任务，你仍保留住了先前没有被测试过的对应关系。” |

### 1.3 准确想起

学生能听懂的定义：提示不完整时，能把学过的信息准确找回来。

#### 任务 A：节点 13｜Deck A 残缺标签复原

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量 Deck A 子集 5—6 在弱提示下能否被准确调出，而不只是从完整答案中再认；这是两项目第一次提取。 |
| 学生心理操作 | 根据只保留主要轮廓、去掉非关键局部的图符提示，主动回忆其双音节虚构名称，再用有限音节块构造完整名称。 |
| 材料形式 | 每次呈现一个残缺但仍可唯一指向目标的图符；提供统一音节块池，其中包含同 Deck 名称所用音节及匹配干扰。不给完整虚构名称选项。 |
| 交互形式 | 依次点击两个音节块组成名称，可清空重选，统一确认；2 个微判断属于同一“复原标签”节点。 |
| 可观察证据 | 两个音节及顺序是否准确；只恢复首音节、音节互换或套用其他配对名称等错误模式；不要求键盘输入。 |
| 评分点 | 每个目标名称设置“两个音节均正确且顺序正确”的完整点，并可保存首音节、尾音节、顺序三个分析标记；正式部分分处理待试测决定，不设固定阈值。 |
| 主要干扰 | 残缺图符过难导致识别失败；音节池过小可靠排除；开放输入带来打字与拼写负担；节点 01/07 提前测试同项目。 |
| 排除设计 | 子集 5—6 在节点 01/07 不出现；认知访谈确认残缺提示可辨但不等同完整图；音节池跨两个目标共享且含同形干扰；使用点击构造，避免输入速度影响。 |
| 预计时间 | 30—35 秒。 |
| 目标难度 | 小挑战。难度来自弱提示下的精确提取，而不是生僻输入或视觉猜谜。 |
| 与另一任务的差异 | A 使用残缺图符作弱提示，并从音节块复原名称；B 使用名称的单个音节和局部轮廓双弱提示，要求从部件库拼回图符。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“提示不完整时，你这次仍能把名称或图形细节较准确地找回来，而不只记住大意。” |

#### 任务 B：节点 30｜Deck B 线索复原

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 以 Deck B 子集 5—6 检查弱提示下精确恢复配对内容的表现，并避免重复任务 A 的“拼名称”方式。 |
| 学生心理操作 | 看到目标虚构名称的一个音节与图符的非诊断性局部后，回忆完整图符；从大部件与小标记组合中拼出原图。 |
| 材料形式 | 每项给一个音节、一个局部轮廓和 2 组部件候选；所有部件来自 Deck B 图符的统一设计语法，不能凭“画风不一样”排除。 |
| 交互形式 | 分别选择主体部件与附加标记，预览组合后确认；不要求自由绘画和精准拖动。 |
| 可观察证据 | 主体、附加标记及相对位置是否全部恢复；是否只记住大轮廓；两个 Deck B 目标间是否串扰。 |
| 评分点 | 完整图符组合正确为主要候选评分点；主体、标记、位置分别记录分析点，是否给部分分由校准决定；微判断仍属于一个节点。 |
| 主要干扰 | 部件组合本身变成空间想象题；局部提示过强；候选组合数太少可枚举；此前节点测试子集 5—6。 |
| 排除设计 | 组合结果即时可见，不要求脑中旋转；提示只提供识别入口而不暴露唯一部件；使用至少两类同风格干扰；节点 18/24 严禁出现子集 5—6。 |
| 预计时间 | 30—40 秒。 |
| 目标难度 | 中等。需以空间操作低负担为前提；若设备或组合理解显著影响表现，应降为有限证据。 |
| 与另一任务的差异 | B 从弱名称与局部轮廓恢复图符；A 从残缺图符恢复双音节名称。两者交换被回忆的内容形式，并使用不同 Deck。 |
| 可进入报告的解释 | 若与任务 A 形成相符证据，可写：“在这次任务中，当线索只给出一部分时，你仍能把学过的对应内容恢复得比较完整。”不能据此推断长期记忆。 |

## 2. 语言

### 2.1 理解意思

学生能听懂的定义：能抓住一句话或一段话真正想表达的内容。

#### 任务 A：节点 02｜临时安排说明

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量能否从短、自然的日常说明中抓住核心要求、适用范围和限制条件，不考词汇量或阅读耐力。 |
| 学生心理操作 | 读懂一段 45—65 字的临时安排，区分“谁适用、要做什么、什么情况例外”，选择不扩大也不遗漏原意的概括。 |
| 材料形式 | 一段校园公共空间或社团物品借用说明；不出现学校制度常识才能判断的内容。选项长度接近，错误项分别体现范围扩大、条件遗漏和重点错置。 |
| 交互形式 | 单项选择后确认；可包含 1 个主判断与 1 个共享文本的范围微判断，但整体仍是一个节点。 |
| 可观察证据 | 是否选择同时保留对象、行动和限制的解释；错误是漏条件、改范围还是抓错重点。 |
| 评分点 | 核心意思正确为主要点；范围与限制识别可作为节点内分析点。最终部分分和权重待校准，不以阅读速度评分。 |
| 主要干扰 | 生僻词、学校生活经验、选项长短提示、过长工作记忆负担、价值立场判断。 |
| 排除设计 | 使用常用词和中性情境；关键信息都在屏幕上；选项句式与长度匹配；答案完全由文本支持；在认知访谈中检查学生是否凭常识而非文本。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 容易。主要检查准确抓意，不靠绕口表达制造错误。 |
| 与另一任务的差异 | A 是单段直接任务，重点是范围和限制；B 是两条短消息组成的跨表征文字版，重点是理解部分—整体与组合条件。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“在这次任务中，你能较准确地抓住短说明真正要求什么，也能留意适用范围和限制。” |

#### 任务 B：节点 03｜组合通知（CR-1 文字版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量以文字呈现时，能否理解三个对象间的部分—整体、最低保留和组合限制；同时作为 CR-1 的文字表征。 |
| 学生心理操作 | 把两到三句短通知整合成一个准确意思，判断哪种执行方式同时符合整体目标和局部限制。 |
| 材料形式 | 三类物品分配或三组报名名额的文字说明，只使用“小部分、其余、至少保留一组”等初中前语言；不要求实际复杂计算。与节点 16 保持相同对象数、关系数和两步判断。 |
| 交互形式 | 先选“哪种概括准确”，再完成一个共享情境的执行选择；2 个微判断统一提交。 |
| 可观察证据 | 是否保留全部限制；是否把“至少/至多”“部分/全部”混淆；CR-1 中与数量版的方向差异只作辅助过程证据。 |
| 评分点 | 准确概括与符合限制的执行选择各为候选评分点；必须同时记录为一个节点表现。跨表征差异不得单独计入能力分数。 |
| 主要干扰 | 数量计算、长阅读、对现实分配公平性的立场、固定关键词猜答案、与节点 16 难度不匹配。 |
| 排除设计 | 仅用小整数或无具体数值的比例词；总字数控制在 70 字内；明确“只根据通知”；选项结构平行；CR-1 制作时先锁定关系图，再分别转写文字与数量形式并人工复核。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自同时保留两项限制。 |
| 与另一任务的差异 | B 是跨表征文字版，要求整合多句及部分—整体限制；A 是独立短说明，主要找核心意思和范围。B 不能单独决定“理解意思”优势。 |
| 可进入报告的解释 | 只有与任务 A 相符且节点质量正常时，才可辅助写：“面对几条需要合在一起看的说明，你这次能把主要要求和限制一起保留下来。”不得输出固定文字入口偏好。 |

### 2.2 理清关系

学生能听懂的定义：能看清句子、信息和观点之间怎样连接。

#### 任务 A：节点 10｜信息关系整理

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量能否区分并整理因果、转折、解释和结论关系，不考形式逻辑术语。 |
| 学生心理操作 | 阅读 4 张短句卡，判断哪句说明原因、哪句形成转折、哪句是综合结论，并恢复自然的信息顺序。 |
| 材料形式 | 中性日常观察情境，例如公共植物养护结果或活动流程变化；每卡 8—16 字，总字数不超过 60 字。关系可由内容而非连接词单独决定。 |
| 交互形式 | 点击卡片按“观察—原因/解释—转折—结论”排列；提供上下移动按钮和点击式替代，不要求拖动。 |
| 可观察证据 | 顺序是否保留语义关系；是否把原因与结果倒置、忽略转折或把例子当结论；修改路径只作过程信息。 |
| 评分点 | 关键相邻关系正确、结论位置正确为候选评分点；最终按整序还是局部关系给分待校准，整个排序只算一个节点。 |
| 主要干扰 | 单纯依赖“所以/但是”关键词；卡片记忆负担；背景知识；拖动操作；存在多个同样合理的顺序。 |
| 排除设计 | 连接词只提供必要自然度，不让单词直接暴露答案；全部卡片始终在屏；材料由双人审查唯一最佳关系；点击上下移动可完成；不需学科知识。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自同时整理三类语义连接。 |
| 与另一任务的差异 | A 直接排列一段信息流，包含因果和转折；B 是 CR-2 文字版，要从文字描述中还原部件的连接、从属和共享关系。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能看清信息之间的原因、转折和结论，整理时不容易只抓住单句。” |

#### 任务 B：节点 19｜文字结构说明（CR-2 文字版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量从简短文字中理清三层对象的连接、从属与共享关系；作为 CR-2 与节点 05 图形结构同构的文字呈现。 |
| 学生心理操作 | 把 4—5 条短说明整合成关系结构，识别谁属于谁、谁与两个对象相连，以及哪项不直接相连。 |
| 材料形式 | 使用无学科含义的代号对象，如“甲台、乙盒、丙片”；关系句均为常用表达。对象数、关系边数、共享节点与节点 05 一致。 |
| 交互形式 | 选择一张最符合文字说明的简化关系卡，随后判断一个关键连接；2 个微判断共享材料。图卡只用作回答载体，不提供额外复杂空间线索。 |
| 可观察证据 | 是否正确恢复从属和共享关系；错误属于反向从属、漏连接还是擅自增加连接；CR-2 形式差异仅作辅助证据。 |
| 评分点 | 整体关系卡正确与关键连接判断正确各为候选点；成对差异不进入主要能力分数，节点不能单独决定机制优势。 |
| 主要干扰 | 代号过多带来工作记忆负担；图卡本身空间复杂；语句歧义；按常识补关系；与节点 05 猜对率不同。 |
| 排除设计 | 对象不超过 5 个并始终显示说明；图卡布局统一，仅连接关系变化；用“只根据说明”限制题外假设；CR-2 两版保持相同选项数、关系数和两步判断。 |
| 预计时间 | 30—35 秒。 |
| 目标难度 | 小挑战。难度来自同时维护多条语义关系，不来自长文本。 |
| 与另一任务的差异 | B 从文字说明恢复静态结构，是跨表征辅助节点；A 直接整理因果、转折和结论的信息流。两者关系类型与情境不同。 |
| 可进入报告的解释 | 仅在任务 A 也支持时，可辅助写：“面对几条相互关联的说明，你这次能把从属、连接和共享关系理得比较清楚。”不能据此宣称固定文字优势。 |

### 2.3 准确表达

学生能听懂的定义：能把意思组织得完整、准确、不容易误解。

#### 任务 A：节点 15｜条件说明组句

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 通过真实构造而非选择“最好句子”，测量能否把行动、条件、例外和结果组织成完整且无歧义的表达。 |
| 学生心理操作 | 根据一张含 3 项事实的提示卡，选择并排列词块，构造一条别人按字面就能执行的说明。 |
| 材料形式 | 中性日常任务卡，例如物品归还或活动签到；事实包含“谁/何时/条件/例外”中的三项。词块池含全部必要信息和 1—2 个会改变范围的干扰块。 |
| 交互形式 | 点击词块进入句子区，可调整顺序、删除和预览；提交的是学生实际构造结果，不是从完整句选项中再认。 |
| 可观察证据 | 关键信息是否保留；条件与结果关系是否正确；修饰范围是否清楚；是否加入冲突信息或留下明显歧义。 |
| 评分点 | 固定记录三类点：关键信息完整、关系正确、表达无明显歧义；具体权重与部分分待试测，不能用单一关键词命中替代整体判断。 |
| 主要干扰 | 打字速度、语法术语、开放作文主观评分、词块顺序存在多种同样正确答案、生活常识补全。 |
| 排除设计 | 全程点击词块，不要求输入；构造规则允许预先审定的等价顺序；评分基于结构化槽位和关系，不评价文采；所有必要事实都在提示卡。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自同时表达条件与例外。 |
| 与另一任务的差异 | A 以完整词块排序构造一条执行说明；B 以有限补全加信息排序构造一条澄清回复，重点处理指代和范围。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能把关键信息和条件组织成较完整的表达，让别人不容易误解。” |

#### 任务 B：节点 25｜澄清回复构造

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在不同沟通情境下再次测量准确表达，重点看能否消除模糊指代、保留先后关系并限定适用对象。 |
| 学生心理操作 | 阅读一条容易误解的短消息和一张事实卡，从有限关系短语中补全关键位置，再排列两条信息形成清楚回复。 |
| 材料形式 | 两人协作安排、物品交接或时间变更情境；事实卡不超过 4 项。候选短语含“只有……才……”“先……再……”等常用表达，但不考语法名称。 |
| 交互形式 | 先点击补全两个结构化空位，再把两条已补全的信息按合适顺序排列并确认；属于一个真实构造节点。 |
| 可观察证据 | 指代对象是否明确；先后/条件关系是否正确；重要信息有无遗漏；组合后是否产生相互冲突或歧义。 |
| 评分点 | 关键信息保留、关系正确、完整无歧义三类评分点与任务 A 共用；另记录指代消歧是否成功，权重待校准。 |
| 主要干扰 | 只凭固定连接词；阅读原消息过长；多种自然表达被误判；交互步骤多；学生追求“好听”而非准确。 |
| 排除设计 | 原消息和事实卡始终显示；所有可接受表达在结构化答案规则中列出；明确说明“重点是说清楚，不是写得漂亮”；先做不计分交互示例。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 容易。材料和操作更短，用来检查准确表达能否跨沟通场景出现。 |
| 与另一任务的差异 | B 侧重指代、先后和澄清，采用有限补全加排序；A 侧重条件、例外和执行说明，采用完整词块构造。两者都是真实构造任务。 |
| 可进入报告的解释 | 若两次构造都提供支持，可写：“在这次任务中，换到不同沟通场景时，你仍能把对象、顺序和条件说清楚。”不能把文采或写作成绩从本任务推出。 |

## 3. 数理

### 3.1 数量感知

学生能听懂的定义：对多少、大小、比例和大致范围比较敏感。

#### 任务 A：节点 04｜点群快速估量

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量不逐个精细计数时对数量多少和大致范围的感知，避免把计算速度当能力。 |
| 学生心理操作 | 短暂查看两到三组稀疏程度不同的点群，估计哪组更多，以及目标点群落在哪个宽范围。 |
| 材料形式 | 黑白或形状冗余编码的规则尺寸容器内随机点群；数量差异经预设控制，不出现可一眼按行列乘法精确计算的整齐阵列。 |
| 交互形式 | 材料短暂呈现后隐藏；先点选“更多的一组”，再选宽范围条；2 个微判断共享同次呈现。无强制反应时限。 |
| 可观察证据 | 大小比较是否正确；范围估计偏高或偏低；作答时间仅用于识别逐点计数或乱答倾向，不直接计分。 |
| 评分点 | 相对多少判断和范围判断各为候选评分点；范围边界和容差需通过试测校准，不能在机制层设固定分数阈值。 |
| 主要干扰 | 精细计数、点大小或密度视觉偏差、屏幕缩放、颜色辨别、规则阵列触发乘法。 |
| 排除设计 | 呈现时间只用于抑制逐点数数并在设备上统一；点大小一致、分布算法平衡拥挤度；不用颜色编码；记录 viewport；小屏可在呈现前适配但呈现中不缩放。 |
| 预计时间 | 15—20 秒。 |
| 目标难度 | 容易。数量差应足以让多数学生形成合理估量，同时保留少量区分。 |
| 与另一任务的差异 | A 是短暂点群的绝对与相对估量；B 是持续可见的比例条与容器填充比较，更强调部分—整体比例感。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“在这次任务中，你对大致多少和比例大小比较敏感，不需要先做复杂计算。” |

#### 任务 B：节点 27｜容器比例判断

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在新场景中测量对部分—整体比例和结果范围的直观判断，不要求通分、百分数或公式。 |
| 学生心理操作 | 比较不同形状但等容量表示的容器填充，判断哪一个接近目标比例，以及合并少量变化后大致落在哪个区间。 |
| 材料形式 | 等长比例条或等面积容器，分割数不超过 8；以形状纹理和边界共同编码，不只用颜色。数值不写成分数或百分比。 |
| 交互形式 | 图形单选加区间单选，选择后统一确认；材料持续显示，避免变成记忆任务。 |
| 可观察证据 | 能否比较比例而非只比较着色面积外观；能否判断粗略结果区间；错误偏向分母、长度或绝对块数。 |
| 评分点 | 目标比例识别与结果区间各为候选点；区间宽度、等价比例接受规则由候选题参数和校准决定。 |
| 主要干扰 | 学过的分数算法、容器形状误导、精细计算、颜色辨别、图示面积并不等价。 |
| 排除设计 | 说明明确“每个容器整体一样多”；几何尺寸标准化；使用粗区间不需精算；以纹理加轮廓编码；认知访谈检查学生是否被块数而非比例吸引。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 中等。难度来自跨不同分割方式比较同一比例。 |
| 与另一任务的差异 | B 材料持续可见，测部分—整体比例；A 短暂呈现点群，测大致数量与范围。情境与视觉组织均不同。 |
| 可进入报告的解释 | 若两个节点相符，可写：“从点的多少换到部分与整体的比例时，你这次仍能较快把握大致大小。” |

### 3.2 数量关系

学生能听懂的定义：能发现数量之间的对应和结构。

#### 任务 A：节点 12｜输入输出卡片

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量能否从少量实例中识别差值、倍数或固定对应结构，不依赖高中公式和复杂运算。 |
| 学生心理操作 | 比较 3 张输入—输出卡，判断哪一种简单数量关系在所有卡上成立，并把它用于一张新卡。 |
| 材料形式 | 小整数、点块或筹码数量，单步运算限于 20 以内的加减或 2—4 倍直观关系；不同候选关系至少在一张示例上被区分。 |
| 交互形式 | 先选关系卡，再选择新输入对应的输出图；2 个微判断共享示例。 |
| 可观察证据 | 是否发现统一关系；能否迁移到新卡；错误是只匹配一例、混淆差值与倍数，还是计算失误。 |
| 评分点 | 统一关系识别和新卡应用各为候选点；应用点不能替代关系识别点形成独立题证据；复杂模型或固定阈值不在本规格冻结。 |
| 主要干扰 | 计算熟练度、学校函数术语、只看首例猜规则、数字太大、文字绕题。 |
| 排除设计 | 使用小整数和图示冗余；全部示例始终显示；不出现公式、坐标或函数名称；候选关系用图形操作卡表达；为计算错误单独记录而不扩大解释。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自跨三个实例确认同一结构。 |
| 与另一任务的差异 | A 是独立输入输出结构；B 是 CR-1 数量版，把同一部分—整体限制用比例条和数量块呈现，需与节点 03 同构。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能看出数量之间稳定的对应关系，并把它用到新的情况。” |

#### 任务 B：节点 16｜分配结构（CR-1 数量版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量以数量图示呈现时对部分—整体与最低保留关系的识别；作为 CR-1 与节点 03 文字意义同构的数量版。 |
| 学生心理操作 | 观察三组数量块及限制标记，找出各部分与整体的关系，再判断哪种分配同时满足两项限制。 |
| 材料形式 | 比例条或不超过 12 个的数量块；用边框、纹理和位置标记“整体、分出部分、至少保留”，不依赖文字长说明。与节点 03 保持对象数、关系数和推理步数。 |
| 交互形式 | 选择一张关系卡，再选择符合限制的分配图；2 个微判断统一确认。 |
| 可观察证据 | 是否识别部分—整体结构；是否同时满足局部和整体限制；与文字版差异只作辅助研究数据。 |
| 评分点 | 数量结构识别与分配应用各为候选点；跨表征成对差异不计入主要能力分数，B 不能单独决定机制优势。 |
| 主要干扰 | 心算、视觉面积不等价、文字标签暗示、对公平分配的常识、与节点 03 的猜对概率或操作量不匹配。 |
| 排除设计 | 只用小数量和可直接比较的等单位块；答案完全由标记关系决定；两版选项数一致；CR-1 按同一关系图分别制作并进行人工同构复核。 |
| 预计时间 | 30—35 秒。 |
| 目标难度 | 小挑战。难度来自同时维护两个数量限制，不来自复杂计算。 |
| 与另一任务的差异 | B 是跨表征数量版，侧重部分—整体与限制；A 是独立输入输出卡，侧重跨实例发现统一对应。 |
| 可进入报告的解释 | 仅与任务 A 相符时可辅助写：“当数量关系被画成块和比例时，你这次能看出部分、整体和限制怎样对应。”不得输出固定数量入口标签。 |

### 3.3 理解变化

学生能听懂的定义：能看懂数量正在怎样变化。

#### 任务 A：节点 09｜双轨变化（CR-3 数量版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量能否从极简数量轨迹中判断方向、幅度和交替变化；同时作为 CR-3 的数量变化表征。 |
| 学生心理操作 | 比较连续 4 个状态，识别两条轨迹分别何时增加、减少以及变化幅度是否交替，再判断下一状态的大致方向。 |
| 材料形式 | 无坐标知识要求的堆叠块或高度条；每步变化为 1—3 个单位，不显示公式。与节点 22 共享“变化类型 A/B 交替并共同决定下一状态”的底层结构。 |
| 交互形式 | 先选变化描述卡，再选下一状态方向图；2 个微判断共享动态图示，可逐步回放但不能自行拖动。 |
| 可观察证据 | 方向、幅度和快慢/交替判断是否正确；是否只看最后一步；与节点 22 的形式差异仅作辅助证据。 |
| 评分点 | 正确描述完整变化和判断下一方向各为候选点；跨表征差异不进入主要能力分数；速度不加分。 |
| 主要干扰 | 坐标图像知识、精确计算、动画播放性能、只凭单步外观、与节点 22 难度不匹配。 |
| 排除设计 | 不使用坐标轴、斜率等术语；所有状态可回看为静态帧；小整数变化；动画加载完才计时；CR-3 两版匹配步数、候选数和目标难度。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 容易。交替结构明显，主要观察能否完整看变化。 |
| 与另一任务的差异 | A 是 CR-3 数量版，以两条数量轨迹呈现；B 是独立新场景，通过流入流出与累计量判断变化快慢和转折。 |
| 可进入报告的解释 | 只有与任务 B 相符时，可辅助写：“你这次能看出数量是在增加、减少，还是变化速度发生了转折。”不得从一对任务推出图表学科能力。 |

#### 任务 B：节点 21｜水位变化卡

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在非坐标的新场景中再次测量对方向、幅度、快慢和趋势转折的理解。 |
| 学生心理操作 | 根据每轮流入、流出和当前水位的简化图，判断水位如何变化，以及在哪一段由“变快”转为“变慢”或反向。 |
| 材料形式 | 3—4 张连续容器状态卡，箭头粗细或单位块表示流入流出；全部关系可用直观比较完成，不需要物理知识和精确减法。 |
| 交互形式 | 选择总体变化描述，再点选发生转折的两张卡之间；材料始终显示，点击区宽大。 |
| 可观察证据 | 能否同时考虑流入和流出；是否识别变化方向与变化速度的区别；转折位置是否正确。 |
| 评分点 | 总体方向/趋势和转折位置为候选评分点；若学生方向正确但快慢判断错，保留分项记录，正式合成待校准。 |
| 主要干扰 | 生活中水流经验、箭头视觉大小、精确心算、把“水位高”当“正在上升”、动画负担。 |
| 排除设计 | 说明“只看图上的流入和流出”；使用静态卡和单位标记；高低状态与增减方向交叉设计；不要求公式；图形尺寸在设备间等比例。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自区分当前数量与变化方向、速度。 |
| 与另一任务的差异 | B 是持续可见的流入流出情境，加入趋势转折；A 是跨表征数量轨迹，重点是交替变化与下一方向。 |
| 可进入报告的解释 | 若两个场景一致，可写：“你在这次任务中不仅能看出数量往哪边变，也能留意变化是加快、放慢还是转向。” |

## 4. 空间

### 4.1 识别结构

学生能听懂的定义：能看清位置、连接、组成和层级。

#### 任务 A：节点 05｜组件连接图（CR-2 图形版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量在图形直接呈现时识别部件连接、从属与共享节点的能力；作为 CR-2 图形表征。 |
| 学生心理操作 | 观察 5 个简单部件和连接线，判断哪个部件属于上层组合、哪个部件被两组共享，以及哪两个不直接相连。 |
| 材料形式 | 无真实物品含义的几何部件、粗连接线和层级框；对象数、关系边、共享节点与节点 19 完全一致。形状用于区分对象，不以颜色编码关系。 |
| 交互形式 | 点选目标部件，再从结构摘要卡中选出正确组成；2 个微判断共享一张结构图，支持放大。 |
| 可观察证据 | 连接、组成和层级识别是否正确；是否漏看共享节点或把邻近误当连接；与文字版差异只作辅助证据。 |
| 评分点 | 关键部件识别和整体结构摘要各为候选点；CR-2 差异不进入主要能力分数；该节点不能独立决定机制状态。 |
| 主要干扰 | 颜色辨别、微小线交叉、视觉搜索速度、屏幕尺寸、图形含义常识、与文字版信息量不等。 |
| 排除设计 | 线条有足够间距并用交叉桥标明确是否连接；形状和文字代号双编码；可放大；节点 19 按同一关系图转写并人工同构复核。 |
| 预计时间 | 15—20 秒。 |
| 目标难度 | 容易。结构可清晰读取，不靠视觉陷阱增加难度。 |
| 与另一任务的差异 | A 是跨表征图形版，呈现抽象连接和层级；B 是独立的新场景静态布局，需要从区域、路径和部件清单核对整体组成。 |
| 可进入报告的解释 | 只有与任务 B 相符时，可辅助写：“结构直接画出来时，你这次能较快看清部件怎样连接和组成。”不得形成固定图形型标签。 |

#### 任务 B：节点 17｜场地布局核对

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在不同静态场景下测量位置、连接、组成和层级识别，排除只会读节点连线图的可能。 |
| 学生心理操作 | 对照一张简化场地布局和部件清单，找出哪个摘要准确描述“哪个区域包含什么、哪些区域由哪条通道相连”。 |
| 材料形式 | 4 个区域、3 条通道和少量无语义图标；布局与清单同时显示。不得使用需要地图常识的方位符号或复杂图例。 |
| 交互形式 | 选择正确结构摘要；可追加一个共享材料的“缺少哪一连接”微判断。支持图形放大和键盘操作。 |
| 可观察证据 | 是否准确识别包含、相邻和连接；错误是漏部件、错层级还是把视觉靠近当作通道。 |
| 评分点 | 正确摘要为主要候选点，关键连接判断为分析点；若设置 2 个微判断，仍按一个节点合成，权重待校准。 |
| 主要干扰 | 地图经验、图标含义、视觉拥挤、读清单的语言负担、颜色或小屏差异。 |
| 排除设计 | 使用无现实含义图标与最短标签；关系由边框和粗线明确；清单不超过 4 行；不用颜色作为唯一线索；记录设备并允许放大。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自同时核对包含与连接两类结构。 |
| 与另一任务的差异 | B 使用区域布局和清单核对，情境更接近日常静态信息图；A 使用纯抽象连接图并承担 CR-2 对照。 |
| 可进入报告的解释 | 若两节点相符，可写：“换到不同结构图时，你这次仍能看清位置、连接和整体由哪些部分组成。” |

### 4.2 脑中想象

学生能听懂的定义：能在脑中形成题目没有完整呈现的画面。

#### 任务 A：节点 08｜遮挡部件补全

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量根据可见部件、连接点和遮挡线索补出未完整呈现整体的能力，不测记忆或绘画。 |
| 学生心理操作 | 观察一个被遮挡的组合体和仍可见的接口，想象遮挡区内哪个部件组合才能让轮廓与连接连续。 |
| 材料形式 | 2D 几何组合体，遮挡区外保留足够的边缘、接口与方向线索；候选补片在大小和复杂度上匹配，不能靠纹理断点一眼排除。 |
| 交互形式 | 点击候选补片后在遮挡区预览，确认前可切换；不要求拖动、绘画或记住消失材料。 |
| 可观察证据 | 补片整体形状、接口位置和边缘连续性是否同时满足；是否只匹配单一局部而忽略整体。 |
| 评分点 | 完整补片正确为主要候选点；接口和轮廓连续可分开记录为分析点，正式部分分待校准。 |
| 主要干扰 | 视觉拼图经验、候选细节差异、工作记忆、精准拖动、二维空间转换负担过高。 |
| 排除设计 | 原图和候选始终显示；预览自动对齐；候选具有相同外框和视觉复杂度；不需要旋转补片；用点击操作把主要需求锁定为“补出未见整体”。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。遮挡信息足够但不直接暴露答案。 |
| 与另一任务的差异 | A 从遮挡边缘补全二维整体；B 从两个不同局部视窗想象同一立体组合，信息来源和场景不同。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“画面没有完整给出时，你这次能利用已知部件和接口，把整体补出来。” |

#### 任务 B：节点 28｜双视窗组合

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在新场景中测量能否把两个局部视窗的信息合并，在脑中形成未直接呈现的整体。 |
| 学生心理操作 | 同时观察一个简单积木组合的正面局部和侧面局部，想象二者属于同一整体时的组成，选出匹配的整体图。 |
| 材料形式 | 最多 4 个等大方块组成的无颜色立体；两个视窗和候选整体始终显示；不使用专业三视图术语，也不要求计算隐藏方块数。 |
| 交互形式 | 选择整体图并可点击查看轮廓放大；候选不要求手动旋转。可含一个共享材料的“哪一块必然存在”微判断。 |
| 可观察证据 | 能否同时满足两个视窗；是否只按一个视窗作答；对隐藏部件的补全是否一致。 |
| 评分点 | 整体选择为主要候选点；同时符合前/侧信息和隐藏部件判断为分析点。微判断不拆为独立题，权重待校准。 |
| 主要干扰 | 学过三视图、立体绘图能力、心理旋转、材料记忆、透视画法理解、小屏显示。 |
| 排除设计 | 用操作示意说明“两个小窗看到同一个物体”而不教答案；视图同时保留；整体候选使用统一等轴画法且无需旋转；方块数少；支持放大。 |
| 预计时间 | 30—40 秒。 |
| 目标难度 | 小挑战。难度来自合并两个局部形成整体，不来自复杂透视。 |
| 与另一任务的差异 | B 合并两个视角并补出简单立体整体；A 根据遮挡边缘补二维组合。B 对多源空间信息要求更高。 |
| 可进入报告的解释 | 若两种场景相符，可写：“从局部线索或不同视角出发时，你这次能在脑中形成比较完整的画面。” |

### 4.3 空间转换

学生能听懂的定义：能在脑中让物体旋转、移动、折叠或换视角。

#### 任务 A：节点 11｜两步位置变换（CR-4 空间版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量连续执行两步旋转/移动后判断方向和位置的能力；作为 CR-4 空间转换表征。 |
| 学生心理操作 | 保留一个简单物体的起始朝向，按顺序执行“转一次、移一次”两项操作，判断最终朝向与落点；理解顺序不可交换。 |
| 材料形式 | 带一个明显方向标记的非熟悉几何片、3×3 无坐标格和两张操作卡；与节点 26 保持两步、一个中间状态和相同候选数。 |
| 交互形式 | 点击查看第一步的临时预览，再选择最终状态；预览只降低工作记忆，不替学生完成第二步。提供点击按钮，不要求拖动物体。 |
| 可观察证据 | 最终方向和位置是否正确；错误发生在第一步、第二步或交换顺序；与节点 26 的形式差异只作辅助。 |
| 评分点 | 最终方向、最终位置为候选分析点，节点整体表现由版本规则合成；CR-4 差异不进入主要能力分数。 |
| 主要干扰 | 操作说明语言、左右混淆、拖动熟练度、反应速度、动画性能、与条件推导版信息量不一致。 |
| 排除设计 | 用图标操作卡和不计分示例；方向同时以凸起标记；允许查看第一步状态；素材加载后计时；两版按同一状态转换表制作并人工复核。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 容易。只有两步且第一步可见，主要观察转换是否准确。 |
| 与另一任务的差异 | A 是 CR-4 的抽象两步变换；B 是独立新场景，要求换观察位置后判断物体相对方向，且不承担跨表征对照。 |
| 可进入报告的解释 | 只有与任务 B 相符时，可辅助写：“物体经过转动和移动后，你这次能较准确地跟住方向和位置。”不得据此认定固定空间优势。 |

#### 任务 B：节点 23｜换位观察

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在新场景中测量换视角后的相对方向和位置判断，避免只重复格子旋转。 |
| 学生心理操作 | 想象观察者沿标明路径移动到另一侧并转身，判断此时两个静态物体分别位于观察者的哪一边。 |
| 材料形式 | 简化圆形平台、观察者朝向箭头和两个形状不同的标记物；不使用东南西北知识，只说“面向箭头、左边、右边、前面”。 |
| 交互形式 | 点击路径终点并选择观察视角图；可用分步按钮查看移动完成但未转身的中间状态，最终统一确认。 |
| 可观察证据 | 能否更新观察者位置与朝向；是否仍用原视角判断；左右与前后错误模式。 |
| 评分点 | 观察者最终朝向和两物体相对位置为候选评分点；具体合成及部分分待校准，速度不参与。 |
| 主要干扰 | 语言上的左右混淆、现实导航经验、动画操作、精准拖动、设备方向或旋转屏幕。 |
| 排除设计 | 使用图示加短语双说明和不计分练习；中间状态可见；只点击不拖动；锁定任务画布方向，横竖屏切换不改变空间关系；物体形状冗余区分。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自同时更新观察者位置和朝向。 |
| 与另一任务的差异 | B 是观察者换位后的视角转换；A 是几何片在格子中的旋转与移动。两者转换主体和场景不同。 |
| 可进入报告的解释 | 若两个节点相符，可写：“从物体转动换到观察位置改变时，你这次仍能跟住方向和相对位置的变化。” |

## 5. 推演

### 5.1 发现关系

学生能听懂的定义：能发现条件、顺序、约束和对应关系。

#### 任务 A：节点 06｜关系配对板

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量从短条件中发现一一对应、不可同组和先后约束的能力，区别于语言语义关系和纯数量关系。 |
| 学生心理操作 | 阅读 3 条短约束，把 3 个无含义角色与 3 个位置进行匹配，找出唯一满足全部条件的对应。 |
| 材料形式 | 图形角色、位置槽和图标化条件卡；条件最多包括“一定对应、不能对应、排在之前”三类，不使用真实身份或生活常识。 |
| 交互形式 | 点击角色再点击位置完成配对；可修改并统一确认；关键中间选择被记录但不要求书写推理。 |
| 可观察证据 | 最终对应是否同时满足全部约束；首先使用了哪条强约束；错误是忽略条件、反向理解还是局部冲突。 |
| 评分点 | 完整匹配为主要候选点；每条约束是否满足作为分析点。中间步骤不成为独立题或额外优势证据。 |
| 主要干扰 | 长题干、角色名称语义、形式逻辑训练、配对操作、工作记忆、只靠排除选项。 |
| 排除设计 | 条件卡始终显示并配图标；角色使用无意义形状与短代号；不提供完整方案单选，而要求实际配对；提供点击替代；条件数控制在 3。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 容易。至少有一条强约束可作为清楚入口。 |
| 与另一任务的差异 | A 侧重一一对应和排他约束；B 使用新场景的流程依赖网，侧重先后、触发与阻断关系。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能发现谁与谁对应、哪些条件互相限制，并据此整理方案。” |

#### 任务 B：节点 29｜流程依赖网

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 在流程新场景中再次测量条件、顺序与约束关系的发现，避免依赖配对题型经验。 |
| 学生心理操作 | 根据 4 张动作卡和 3 条依赖规则，找出哪个动作必须先发生、哪个动作会阻止另一动作，以及一个可行顺序。 |
| 材料形式 | 无学科背景的设备开关或整理流程，以形状代号表示动作；规则卡使用“完成甲后才能乙”“丙开启时不能丁”等短句和图标。 |
| 交互形式 | 先点出关键先行动作，再排列 4 张动作卡形成可行流程；点击移动替代拖动。 |
| 可观察证据 | 是否发现依赖和阻断关系；可行序列是否满足全部条件；错误集中于漏条件、顺序反转或把可选当必需。 |
| 评分点 | 关键关系识别和完整可行序列为候选评分点；若存在多个可行序列，答案规则必须全部接受；固定阈值待校准。 |
| 主要干扰 | 文字阅读负担、现实设备常识、排序操作、条件太多导致工作记忆主导、误把关系词当语言题。 |
| 排除设计 | 所有规则持续显示；动作使用无语义代号；条件数不超过 3；用程序枚举确认接受所有有效序列；文字保持短且关系类型清楚。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自依赖与阻断两类约束共同出现。 |
| 与另一任务的差异 | B 是流程中的先后、触发和阻断；A 是角色与位置的一一对应、排他和先后。两种关系网络及交互不同。 |
| 可进入报告的解释 | 若两个场景相符，可写：“从配对换到流程安排时，你这次仍能看出条件之间怎样限制、触发或决定先后。” |

### 5.2 找到规律

学生能听懂的定义：能从多个变化中归纳共同规则。

#### 任务 A：节点 14｜属性轮换卡

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量从多个非数量状态中归纳共同变化规则并应用到新情况，避免熟悉数列套路。 |
| 学生心理操作 | 比较 4 张状态卡，分辨形状、位置和标记三个属性中哪些按固定方式变化，归纳组合规则后选出下一张。 |
| 材料形式 | 2—3 种简单形状、三个位置和一个纹理标记；规则采用轮换、交替或两属性同步，不用数字序列、字母表或文化图案。 |
| 交互形式 | 可逐张查看全部状态，先点选“哪些属性在变”，再选择下一状态；2 个微判断共享序列。 |
| 可观察证据 | 是否从多个状态找到共同变化；是否只延续最后一步；能否把规则用到新状态；猜题路径。 |
| 评分点 | 变化属性识别与下一状态应用各为候选点；只有应用正确但规则选择矛盾时保留质量标记，不按单个微判断独立解释。 |
| 主要干扰 | 学校数列经验、颜色辨别、图形细节、候选项排除、工作记忆、存在多条同样可行规则。 |
| 排除设计 | 全部状态始终显示；用纹理和形状而非颜色单编码；候选规则经过枚举，确保给定状态下只有一个最简且完整解释；不出现数字。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。使用两项属性的清楚变化，不以复杂图形增加难度。 |
| 与另一任务的差异 | A 是独立非数量属性序列；B 是 CR-3 抽象规律版，与节点 09 的双轨交替变化同构，规则含两个变化过程的组合。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能从几个变化里找到共同规则，并把规则继续用下去。” |

#### 任务 B：节点 22｜双规则状态（CR-3 抽象版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量以抽象属性呈现时能否归纳两种变化交替出现并共同决定下一状态；作为 CR-3 的规律版。 |
| 学生心理操作 | 观察连续状态，识别规则 A 与规则 B 轮流作用，保留两条变化线索并推出下一状态。 |
| 材料形式 | 位置、开口方向或纹理数量的抽象状态卡；不用数字数列。与节点 09 保持状态数、交替次数、推理步数和候选数。 |
| 交互形式 | 先选择最符合全部状态的规则组合，再选择下一状态；2 个微判断统一提交。 |
| 可观察证据 | 是否发现交替而非单一重复；能否同时跟住两条规则；与数量版方向差异只作辅助研究证据。 |
| 评分点 | 规则组合识别和新状态应用各为候选点；跨表征差异不进入主要能力分数，B 不能单独决定机制优势。 |
| 主要干扰 | 图形视觉搜索、心理旋转、候选项猜测、熟悉图形推理题、与节点 09 难度或视觉负担不匹配。 |
| 排除设计 | 只用大而清楚的属性差异；不要求旋转复杂图形；候选项在单一规则下都具有迷惑性，须同时满足两条；CR-3 由同一状态转换表生成两版并人工复核。 |
| 预计时间 | 30—35 秒。 |
| 目标难度 | 小挑战。难度来自同时归纳两条交替规则。 |
| 与另一任务的差异 | B 是跨表征抽象双规则，承担 CR-3 对照；A 是独立属性轮换，只需从多属性中锁定一个组合变化方式。 |
| 可进入报告的解释 | 仅与任务 A 相符时，可辅助写：“当变化由两条规则轮流推动时，你这次仍能找到共同方式并推出下一步。”不得据此贴“规律型”标签。 |

### 5.3 推出结论

学生能听懂的定义：能只根据已有条件一步步得到必然结论。

#### 任务 A：节点 20｜条件卡必然结论

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量能否只使用给定条件完成 1—2 步推导，并区分“可能”与“一定”，不依靠现实常识和立场。 |
| 学生心理操作 | 读取 3 张简短条件卡，先保留一个中间关系，再判断哪个结论在所有符合条件的情况下一定成立。 |
| 材料形式 | 无现实意义的角色、盒子或开关代号；条件包括包含、互斥或单向触发。结论选项分别包含必然、可能但非必然、与条件冲突和题外假设。 |
| 交互形式 | 可点击条件卡标记“先用哪条”，随后单选必然结论并确认；中间标记用于过程记录，不单独评分为题。 |
| 可观察证据 | 结论是否由条件必然推出；是否逆推单向条件、加入常识或把可能当一定；关键中间关系是否保留。 |
| 评分点 | 最终必然结论为主要候选点；中间关系选择作为分析点和质量证据，是否给部分分待校准。 |
| 主要干扰 | 语言长度、形式逻辑术语、现实经验、选项语气强弱提示、纯排除、工作记忆。 |
| 排除设计 | 条件卡始终显示；使用短句和图标冗余；明确“只根据卡片”；选项语气结构平行；不用“充分/必要”等术语；材料经穷举验证唯一必然答案。 |
| 预计时间 | 20—25 秒。 |
| 目标难度 | 容易。控制在两步内，并提供可标记的中间关系。 |
| 与另一任务的差异 | A 是独立条件卡推导，直接判断必然结论；B 是 CR-4 条件推导版，把连续两步空间操作改写为状态触发规则。 |
| 可进入报告的解释 | 若与任务 B 一致，可写：“你在这次任务中能只根据已有条件保留中间关系，推出一定成立的结论。” |

#### 任务 B：节点 26｜状态操作推导（CR-4 条件版）

| 规格字段 | 设计要求 |
|---|---|
| 测量目标 | 测量以条件规则呈现时能否按顺序执行两步状态变化并推出必然结果；作为 CR-4 与节点 11 同构的条件推导版。 |
| 学生心理操作 | 根据“若处于状态 X，操作甲会变为 Y；随后操作乙会改变位置但不改变标记”等规则，保留中间状态并判断最终结论。 |
| 材料形式 | 起始状态卡、两张按顺序排列的规则卡和最终结论选项；不用空间旋转图，只用符号状态、位置槽和短句。状态数、两步顺序、候选数与节点 11 一致。 |
| 交互形式 | 先选择中间状态，再选择必然的最终状态；两步统一提交，中间状态可视化保留。 |
| 可观察证据 | 是否按正确顺序应用两条规则；能否保留中间状态；是否擅自交换规则或加入未给条件；与空间版差异仅作辅助。 |
| 评分点 | 中间状态与最终结论各为候选点，整体为一个节点；CR-4 成对差异不进入主要能力分数，不能单独决定机制状态。 |
| 主要干扰 | 文字理解、符号记忆、把任务当空间题、逆推规则、与节点 11 操作量或猜对率不同。 |
| 排除设计 | 规则卡始终显示并配状态示意；短句使用统一句型；不要求记忆；两版源自同一状态转换表并进行人工同构复核；选项数和两步结构匹配。 |
| 预计时间 | 25—30 秒。 |
| 目标难度 | 中等。难度来自顺序执行两条规则和保留中间状态。 |
| 与另一任务的差异 | B 是跨表征条件规则版，强调必然推导；A 是独立的包含、互斥、触发条件卡。两者条件类型和情境不同。 |
| 可进入报告的解释 | 仅与任务 A 相符时，可辅助写：“条件按顺序发生时，你这次能跟住中间状态，判断最后一定会出现什么结果。”不得输出固定推理入口偏好。 |

## 6. 评分、解释与生产交接规则

### 6.1 节点评分记录

每个候选节点至少保存以下结构化信息：节点版本、主要能力、主要机制、任务角色、微判断数、每个评分点、学生最终答案、答案修改、素材显示时间、首次操作时间、提交时间、有效作答时长、后台时长、中断、设备和屏幕信息。正确答案、评分规则和权重不下发前端。

节点原始表现可以在探索阶段按“有效得分点 ÷ 有效总分点”保存，但只能用于题目分析。正式机制证据必须使用同版本、同目标年级的校准参数或查表规则，并考虑节点信息量、局部依赖和质量标记。本文不提供任何固定正确数、时间或分数阈值。

### 6.2 两任务合成边界

- 任务 A 与任务 B 是同一次测评中的两个情境证据，不代表跨时间稳定性。
- 两节点相符时，最多支持“优势证据较一致”；一个较清楚、另一个较弱但不冲突时，可支持“出现优势线索”；冲突、异常或证据不足时为“需要补充证据”。具体界限只能由校准数据确定。
- 任何跨表征节点都不能单独决定上述状态。跨表征成对差异独立保存，只作为题目研究和可能的报告辅助证据。
- 记忆节点若发现子集被提前呈现、重复提取、断点恢复导致异常复习机会或实际延迟严重偏离版本分布，应标记证据受限或无效，不得照常解释。
- 空间任务若设备、缩放、资源加载或交互错误显著影响完成，应优先标记质量问题，不得把设备问题解释为能力不足。

### 6.3 候选题生产时必须补齐

本文是情境规格，不是最终题。每个候选任务还必须补齐：最终材料资产、所有可接受答案、干扰项生成理由、微判断数量、题目版本、素材版本、无障碍文本、移动端尺寸、同构复核记录、内容审查记录以及预计难度的专家依据。完成认知访谈和试测前，只能写“目标难度”，不能写“实测难度”或“已验证”。

### 7.3 约束检查

| 检查项 | 结果 |
|---|---|
| 五项一级能力齐全 | 是：记忆、语言、数理、空间、推演各 6 个节点 |
| 15 个二级机制齐全 | 是：每项一级能力 3 个机制 |
| 每个机制正好 2 个任务规格 | 是：任务 A 15 个、任务 B 15 个，共 30 个 |
| 每个任务包含 12 个指定字段 | 是：测量目标、学生心理操作、材料形式、交互形式、可观察证据、评分点、主要干扰、排除设计、预计时间、目标难度、与另一任务的差异、可进入报告的解释 |
| 语言包含真实准确表达 | 是：节点 15 为词块组句，节点 25 为有限补全加排序；两者均提交真实构造结果，不是完整句再认 |
| Deck A/Deck B 不重复提取 | 是：每套 1—2 仅快速记住，3—4 仅保持记忆，5—6 仅准确想起；每项目只进入一个计分节点 |

| 不设置固定分数阈值 | 是：所有界限、部分分与权重均留待试测和校准 |
| 微判断不作为独立题 | 是：所有节点明确共享材料、统一提交或按节点合成 |
| 不引入高中知识点 | 是：只使用日常短文本、小整数、直观图示、简单空间与抽象关系；仍须由学科教师进行候选题复核 |
| 难度覆盖 | 每项能力均以专家目标覆盖 2 个容易、3 个中等、1 个小挑战；实际难度待试测 |
