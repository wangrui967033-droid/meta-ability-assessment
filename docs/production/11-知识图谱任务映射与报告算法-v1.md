# 知识图谱任务映射与报告算法 V1

**用途**：把“元能力快测”的结果，转成学生真正能用的“先在哪些学科、哪些知识内容上投入”的建议。

**报告承诺**：帮助学生看见更顺的学习方式，并把它先用到最值得投入的学科和知识内容上。

**不做的事**：不依据一次快测给学科排第一到第十名；不判断学生是否“适合/不适合”某一科；不预测高考分数。

---

## 1. 算法的基本单位不是“学科”，而是“知识任务”

“数学”不能只对应一组固定权重。学生真正遇到的是函数图像、几何结构、数列关系、概率统计等不同任务；它们调用的底层能力不同。

因此，映射链路固定为：

`知识图谱节点 → 可学习的知识任务 → 所需元能力与小能力 → 学生当前更顺的入口 → 可执行学法`

例如：

`数学 / 函数及其性质 → 看图像与变量变化 → 理解变化、识别结构、发现关系 → 先画谁在变、怎么变，再进入公式`

报告展示的“数学｜优先练习区”，含义是：数学里有较多重要任务正好能使用学生当前较明显的学习入口；并不代表数学整体“天赋最高”。

## 3. 五元能力与小能力字典

| 一级能力 | 小能力 | 学生端的说法 |
|---|---|---|
| 记忆 | 快速记住 / 保持记忆 / 准确想起 | 留住关键信息、隔一段时间还能找回来 |
| 语言 | 理解意思 / 理清关系 / 准确表达 | 读懂材料、分清信息、说清答案 |
| 数理 | 数量感知 / 数量关系 / 理解变化 | 看懂多少、对应关系和变化 |
| 空间 | 识别结构 / 脑中想象 / 空间转换 | 看清组成位置、补出整体、跟住图形变化 |
| 推演 | 发现关系 / 找到规律 / 推出结论 | 找联系、看规律、顺着条件往下想 |

数据层只保存上述规范名；学生端不展示“机制”一词，而显示为“看清结构”“找到关系”等日常表达。

## 6. 从学生结果到报告的计算规则

### 6.1 先找优势学科，再找优势任务

学生确实需要看到“我的优势学科”和“我的优势任务”。算法分两层：

```text
学生五元能力画像
  × 学科底层能力权重（学科×记忆/语言/数理/空间/推演表）
  = 优势学科候选

优势学科候选
  × 该科知识图谱任务的能力组合
  × 该任务的二级机制证据
  = 优势任务
```

第一层回答“你的优势更容易在哪几科发挥”；第二层回答“在这门科目的哪些内容上，应该先用它”。学科权重表不展示为学生分数，只作为算法底盘。报告呈现为“优势较容易发挥 / 有较好切入点 / 可以借助优势进入”，而不是学科总分排名。

例如空间、推演证据更集中的学生，可能得到：

> **优势学科：数学、物理、地理**  
> **优势任务：** 数学的函数图像和几何结构；物理的受力分析、运动图像；地理的地图定位和自然过程链。

这不是“你天生适合这三科”，而是“这三科的这些内容更值得优先用你的优势方法进入”。

### 6.2 输入

后端提供：

- 五个一级能力的连续表现信号；
- 15 个小能力的状态和覆盖度；
- 每项状态所来自的独立任务节点数；
- 外语语种（英语或日语）。

学生端绝不显示原始分数、排名、阈值、作答速度或“能力等级”。


服务端计算任务的`学习入口匹配度`时，应同时看：

1. 该任务调用哪些一级能力；
2. 该任务最关键的小能力，在学生测评中是否有足够独立任务支持；

图谱的分值、占比和模块规模可以作为报告的**背景参考**展示给学生，但不进入元能力推荐、排序或分组。推荐只依据学生元能力表现与该一级模块所需元能力的匹配。
4. 是否有与之明显冲突或证据不足的情况。

V1 不把“快”直接算成更高匹配度；速度只用于异常作答排查和同构任务辅助比较。

### 6.4 输出不是排名，而是“投入区”

先聚合知识任务，再聚合到学科。输出三类，不显示“第一、第二、第三”或百分比横条：

| 学生端标签 | 含义 | 报告要给什么 |
|---|---|---|
| 现在最值得优先投入 | 该科有多个重要知识任务能稳定使用学生当前更顺的入口 | 学科名 + 2–4 个具体知识任务 + 一个进入方法 |
| 接下来可以多练 | 该科有明显切入任务，但支持还没有覆盖到足够多的核心内容 | 学科名 + 1–3 个知识任务 + 一个进入方法 |
| 可以借这套方法进入 | 可以用当前优势帮助理解，但不能仅靠它完成整科 | 学科名 + 1–2 个切入任务 + 提醒基础仍需补齐 |

每名学生最多展示：

- `现在最值得优先投入`：2–3 科；
- `接下来可以多练`：2–3 科；
- 其余课程进入第三类，不堆叠成冗长排名。

英语与日语互斥：只将学生填写的外语语种放入学科输出。

### 6.5 05「优势学法」如何生成

先生成一条**总学习方法**，再给四条“学/背/练/补”建议。

模板：

`最常使用的一级能力 + 最有支持的小能力 → 可观察的学习动作`

例：空间 + 推演较突出：

> 你的总学习方法：先看见，再连起来，最后做出来。先把结构或过程画清楚，再找条件之间的关系，最后进入公式、记忆或解题步骤。

然后从“现在最值得优先投入”的知识任务里选不同学科，避免四条建议都重复说“画图”：

| 动作 | 选择规则 | 示例 |
|---|---|---|
| 学 | 选一个新概念/新图像任务 | 学函数：先画谁在变、怎么变，再进入公式 |
| 背 | 选一个需要保留过程或线索的任务 | 背地理过程：画条件→变化→结果，再遮住回忆 |
| 练 | 选一个综合推断任务 | 练物理过程题：先画对象、状态和变化，再列关系 |
| 补 | 选一个最容易诊断错误位置的任务 | 补几何：先分图没看清还是关系没推出 |

## 7. 开发顺序与校验

1. 把第 4 节任务族录入为`subject-task-map`种子数据；
2. 为每条任务族关联图谱中的具体二级/三级节点 ID；
4. 后端接入任务匹配和投入区聚合；
5. 报告端只消费“投入区 + 知识任务 + 进入方法”，不自行排序；
6. 逐项审查报告文案：不写“你喜欢”“你主动”，只写“这次更容易”“可以先这样做”；
7. 在有足够真实样本后校准参数。V1 不把尚未校准的阈值当成科学结论。

## 8. 当前完成定义

完成后，一份学生报告不再只写“空间更突出”，而能写成：

> 你遇到复杂内容时，更适合先把它画出来、弄清结构和关系。建议先把这套方法用在数学的函数图像和几何结构、地理的地图与过程题、物理的过程和关系题上；每次先画，再找关系，最后进入公式或答案。

这就是“元能力快测 → 知识图谱 → 学科学习动作”的完整闭环。
