# 元能力学习入口测评

面向浙江新高考学生的移动端测评与学习任务报告原型。项目以五项元能力（记忆、语言、数理、空间、推演）连接题库作答、能力支持状态、学科方向和具体学习任务。

当前版本为可内测的前端 V1.6 原型：任务与学科使用统一分类逻辑，报告面向学生展示“优势可发挥任务、可借力任务、待发展任务”。原型阈值仅用于产品验证，后续应以真实学生样本完成校准与效度验证。

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:5173/`。

## 部署说明

执行 `pnpm build` 后，静态前端产物输出到 `dist/`，可由任意静态 Web 服务托管。

本仓库当前尚未包含生产后端：题库答案、计分与报告生成仍在前端原型代码中。正式部署前，应将题库与答案校验、作答会话、结果计算、报告存储和权限控制迁移至后端，并通过环境变量管理数据库和密钥。

## 当前原型范围

- 姓名与手机号校验；
- 25 道题：17 道直接任务与 4 组同构比较；
- 记忆、语言、数理、空间、推演五维画像；
- 测评后选择浙江新高考 7 选 3 科目；
- 学生版报告：核心结论、元能力画像、学科发挥方向与学科任务指南；
- 当前作答记录仅保存在浏览器本机。

题库、常模、学科权重和结果阈值属于产品原型配置。正式发布前仍需经过认知访谈、样本校准、复测信度和独立样本验证。仓库应保持私有，直至题库与答案校验逻辑完成服务端迁移。
