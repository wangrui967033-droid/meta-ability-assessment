# 学科与任务分类：V1直接分类规则

## 单一决策入口

学科、任务及兼容入口均使用 requirement-support.ts。

1. 缺少主要要求、有效作答或任务映射不足：unknown，不展示；pendingReason=insufficient。
2. 关键要求有重复未得分缺口，已有优势不能绕过：attention。
3. 主要要求及额外关键要求全部达到支持标准：supported。
4. 未全部达标，但达标能力有明确动作可直接参与，且没有关键缺口阻断：entry。
5. 其余信息充分但未达支持标准、无有效入口的任务：attention，作为建议加强方向，而非已证实的明显能力缺陷。

| 内部状态 | 学科分类 | 任务分类 |
|---|---|---|
| supported | 优势发挥区 | 优势可发挥任务 |
| entry | 优势借力区 | 可借力任务 |
| attention | 待发展区 | 待发展任务 |
| unknown | 不展示 | 不展示 |

## 阈值与稳定性

- classification-policy.ts 中的0.75仍为待真实学生数据校准的原型阈值，不是科学常模或能力分界线；使用未四舍五入得分。
- 分组删除后的上下界只产生内部 stabilityReview 复核标记，不再阻止分类，不再把完整临界作答隐藏。
- 保留证据有效性、机制覆盖、重复/冲突记录排除以及关键重复零分阻断。全零分是有效作答，未作答不是低能力。
- 75%样例可以直接归类；“优势”仅指当前原型要求得到支持，不表示已经验证学科擅长或保证得分。
- 借力动作只取已有配置，不用无关高分代替关键要求；全部路径仍待教研及真实任务表现验证。

## 报告边界

四个板块、视觉风格、三个用户可见任务分类不变。不新增补题。02/03/04使用同一支持状态；待发展表示建议加强，不一概称为明显缺口。只有信息不足的任务隐藏。

## 验收

模拟22个场景、1024个能力组合，对3840组单项表现提高的相邻画像检查：同一任务不得从可见变隐藏。继续验收阈值附近换类、同分不同组题分布、关键要求阻断及上下层一致性。

整批换类预警不自动修改分类比例。25%的审核预警线仅用于开发验收，不参与学生分类。当前推演约67%→75%仍有97/154项任务换类，75%→83%无换类；不能宣称阈值敏感性已经消除。

直接分类前版本保存在项目外“版本备份/直接分类前-20260909/源码与HTML.tar.gz”；更早用户要求的HTML备份保持不变。
