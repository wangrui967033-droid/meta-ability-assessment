# 学生用语与8秒点阵：修改及模拟测试说明

## 结论

已完成题目引导、记忆说明、报告全部五个板块和报告页尾的学生用语修改；点阵改为加载完成后显示8秒，再收起作答。三位隔离的模拟者均完成30/30组并查看报告。

这次是模型操作真实页面的可用性走查，不是真人学生研究。320、410、490分只用来描述不同学习背景，没有据此预设智力、记忆或应得分数。模拟的测评正确率不用于证明题目适合这一分数段。

## 本次已经修改

- 题目说明：“对象—属性”改成“名字和特点”；“外边界”改成“拼好后的外轮廓”；旋转、拼接、连线规则改为直接告诉学生可以做什么、不能做什么。
- 报告：标题、五项能力解释、十五项机制解释、学科分组说明、全部学科学习方法、无明显高分项的提示和页尾都纳入检查。保留“准确表达”等已确认名称及“待发展”。
- 报告最终称呼：“我的优势怎么用”改为“这几项能力怎么用”；“更容易用上优势”改为“能用在关键步骤”；“可以用优势起步”改为“可以帮你入手”。不把一次任务得分直接称为稳定优势。
- 点阵：点击准备按钮才展示；图片加载完成后计时8秒，有倒计时；收起后才能选。第二题独立开始。完整观看后刷新不重播；中途离开时提示中断，换同数量的新布局再看。
- 根据盲测的共同反馈，补上“这组有2题”，解释为什么第一题答完还不能继续。
- 正确答案、选项映射、计分、六格位置选项、学科需求值≥3的展示规则保持不变；没有加入“两题相差50个百分点就不一致”的规则。

点阵仍归数理，不改变记忆计分公式。它会改变整个作答过程的实际用时，因而可能改变后续记忆题的保持间隔；程序继续记录材料结束至入题/提交的实际间隔，不将时间加减进分数。8秒内仍可能逐个计数，本次修改不等于验证了纯粹“近似数感”。

交付版本：1.6-student-8s-20260907。新版本使用独立会话记录，不覆盖旧版作答；新旧呈现条件下的结果不直接混比。

测试者没有读取源码、答案、内部数据或彼此的结果。三人均发现了可以照做的学习方法；例如数学找第一处错误并合上解析重做、语文给判断标原文依据、地理遮住标注再补全。

重要限制：三位测试者都没有通过工具完整观察到两段逐个闪现的符号，相关作答含不确定选择。这是自动化观察通道的限制，不应解释为学生记忆差，也不能证明产品漏播。页面记录的用时包含工具往返和截图停留，不能用来验证或否定真人15～18分钟的时长估计。长知识点清单主要是通览，不是逐项学习验证。

## 发现与处理

| 优先级 | 证据与问题 | 当前处理 |
| --- | --- | --- |
| 高 | 三人均观察到三项或四项并列100%，但摘要与金色只突出语言、数理，后续学科分类也沿用这两项。页面未说明为何选择两项 | 未改算法或并列展示逻辑。建议下一轮先处理并列情况，再检查学科分类连带影响 |
| 高 | 学习方法位于大量知识点清单之后。320画像的四科报告约29,008px高，第05部分约在23,370px处；未见目录/学科跳转 | 未重排布局。建议把一项可立即执行的方法提前，长清单按需查看 |
| 中 | 前面说不能判断优势，后面仍反复称“优势” | 最终版本已统一上述标题和分类称呼；自动化回归通过，未重跑三次完整盲测 |
| 中 | 360px手机下复杂图形的端点、细线及图内标签较小，比较时需要反复看；其他模拟者的感受较轻 | 保留为可读性问题，未擅自改变图形几何或题目难度 |
| 中 | 百分比的含义、并列选择依据，以及目录“约X分”的地区/年份/卷型范围，学生从界面无法确认 | 未新增未经核实的解释、常模或考试分值结论 |
| 低 | 点阵第一题选完才出现第二题，继续仍灰色，三人都曾短暂停顿 | 最终版本已补“这组有2题”；原始盲测截图保留，不能当修改后再次验证 |

“找不到方法会放弃”“不愿付费”“可能误读为学不好”均是模拟者推断，不是实际学生行为统计。没有发现导致无法完成30组或生成报告的产品级阻断。
