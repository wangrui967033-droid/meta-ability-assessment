05｜我的学科学习方法

这门课本来怎么学？我的优势又能帮在哪里？

每门课都有自己的学习规律。下面先给出完整路径，再告诉你可以怎样试着用上优势。它是一个值得验证的学习入口，不是对你能力的固定判断。

语文

01学科规律语文的完整学习路径
  1. 积累语言材料
  2. 读懂内容
  3. 组织信息
  4. 形成判断
  5. 表达与修改
02优势作用先试语言理解，再试空间整理

语言可以先用自己的话说出内容和观点，再回到原文找依据，看看是否更容易读清和表达。

空间可以尝试把空间优势用在文章结构整理上，看看它能否帮助你更快看清段落关系。

03我的学法更适合你怎么完成

先从读懂意思开始

  1. 说出大意
  2. 分清层次
  3. 找到依据
  4. 组织表达

先把内容讲明白，再做分析和表达。

英语

01学科规律英语的完整学习路径
  1. 词汇语法打底
  2. 放进语篇
  3. 读懂信息
  4. 说写表达
  5. 纠错再用
02优势作用先试语言理解，再试空间整理

语言可以把单词和语法放回句子里，先读懂它在表达什么，看看是否更容易记住和使用。

空间可以试着分出段落作用，标清信息位置和前后联系，看看回原文时是否更快。

03我的学法更适合你怎么完成

先从完整句子开始

  1. 弄懂句意
  2. 看清上下文
  3. 找到关键信息
  4. 尝试表达
  5. 订正再用

词汇和语法要放进句子里学，技巧放进练习里用。

数学

01学科规律数学的完整学习路径
  1. 理解概念
  2. 看懂基本关系
  3. 建立题目模型
  4. 推理运算
  5. 变式与复盘
02优势作用先试空间呈现，再试语言拆解

空间可以先把图形、函数和变化关系画出来、标清位置，再进入公式，看看关系是否更容易看懂。

语言可以先说清已知什么、要求什么，再把长条件拆成几条数学关系。

03我的学法更适合你怎么完成

先把关系变得看得见

  1. 读清条件
  2. 画图或列表
  3. 写出关系
  4. 推算检验

先看清关系，再把关系写成式子。

物理

01学科规律物理的完整学习路径
  1. 理解概念规律
  2. 还原实际情境
  3. 建立物理模型
  4. 推算与验证
  5. 实验和复盘
02优势作用先试空间还原，再试语言确认

空间可以先画出研究对象、方向、状态和变化过程，看看关系是否更容易看清。

语言可以先说清研究谁、发生什么、求什么，再检查有没有看漏条件或混淆对象。

03我的学法更适合你怎么完成

先把过程还原出来

  1. 确定对象
  2. 画出过程
  3. 标出条件
  4. 建立模型
  5. 推算验证

先还原发生了什么，再决定用哪条规律。

先从顺手的地方开始，再把优势慢慢带进更多学习任务。
